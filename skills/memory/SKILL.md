# memory：类人脑记忆

一个本地记忆库。**分主次**（偏好 0.81 分，日常待办 0.35 分）、**会休眠**（沉下去但不删）、**被提到才想起**（不是全量塞进上下文）、**情绪会累积成趋势**。

数据在本机 `~/.human-memory/memory.db`，零联网、零上传。

---

## 一、两条命令就够

**取记忆**（每轮回复前跑，看有没有相关的）：

```powershell
python "C:\Users\Lenovo\.dsh\skills\memory\scripts\memcli.py" recall "用户刚说的话"
```

**记记忆**（用户说了关于他自己的事，跑一次）：

```powershell
python "C:\Users\Lenovo\.dsh\skills\memory\scripts\memcli.py" add "用户的原话"
```

工作目录无所谓，路径是绝对的。

---

## 二、什么时候取（recall）

**每轮用户说话后，先 recall 一次**，把结果看一遍再回复。开销是毫秒级。

recall 无结果时输出 `（没有相关记忆）`，直接忽略。

召回结果会显示来源标记：`[偏好·0.81·3天前] 我讨厌香菜`。**把它自然融进回复**，比如：

> 用户：今晚吃什么？
> 记忆：我讨厌香菜
> 回复：避开香菜就行，其他你定。

**不要说**"根据我的记忆库""系统记录显示"这类话——那会暴露机械感。就当是你记得。

---

## 三、什么时候记（add）

**该记**（用户关于自己的陈述）：
- 身份：我叫什么、我是做什么的、我住哪
- 偏好：我讨厌/喜欢什么、爱吃、过敏
- 关系：我女儿五岁、我妈最近住院
- 情绪状态：今天很累、心情低落、特别焦虑
- 事件：被老板骂了、跟同事吵架
- 心结：还在生谁的气、什么事过不去
- 长期计划：明年想学什么

**不该记**：
- 问句（"我讨厌什么？"）——脚本会自动拦
- 语气词（"好的""嗯嗯"）——脚本会自动拦
- 用户让你做的事（"帮我查一下…"）
- 你自己说的话

**记原话，别改写**。用户说"累死了"就记"累死了"，不要润色成"感到疲劳"。

## 四、情绪和心结

**看近期状态**：用户问"我最近怎么样""是不是状态不好"时：

```powershell
python "..." mood
```

输出会包含：连续低迷天数、趋势方向、未化解的心结、仍在余波中的事件。例如：

```
最近 7 天共 8 条情绪记录，整体偏负面
已经连续 7 天状态偏低，不是单日波动
心结（还没过去，强度 0.82）：4天前「我还在生我妈的气」
仍在余波中：2 天前「被老板当众羞辱」，可能还要影响约 8 天
```

**回应这类信号时要更谨慎**：连续低迷不是"今天心情不好"，是状态。

**心结怎么化解**：用户说"算了""都过去了""想开了"——正常 add，脚本会记为化解信号（一次不够，要时间+多次表达+状态转正）。**不要替用户宣布"这件事已经过去了"**。

## 五、其他命令

| 命令 | 用途 |
|---|---|
| `memcli.py list` | 看全部记忆（含休眠/被取代） |
| `memcli.py stats` | 条数统计 |
| `memcli.py explain 3` | 看第 3 条为什么是这个分（六因子明细） |
| `memcli.py context "话题"` | 一次给「相关记忆 + 近期状态」，适合注入回复 |
| `memcli.py sleep 3` / `wake 3` | 手动休眠 / 唤醒 |
| `memcli.py pin 3` | 钉住（永不沉底） |

---

## 六、红线

1. **只记用户说过的**，不要自己编造记忆内容。
2. **不要每句话都记**——只有关于用户自己的陈述才记，否则库里全是垃圾。
3. **recall 结果只作参考**，和用户当前说的矛盾时以当前为准（记忆可能过时）。
4. **不联网**。这个 skill 全程本地，不要调用任何外部 API。
5. **不要主动炫耀记忆能力**。用得自然，别每次都提"我记得你…"。
6. 用户明确说"忘掉这个"时，用 `memcli.py sleep 编号`（软删）而不是删除文件。
