# DSH 内的记忆宇宙

调用 `memory_universe_open` 工具。用户说星图、行星用 `view="planets"`，记忆宇宙、脑图、关联网络用 `view="network"`；未指定时用 network。默认定位当前真实会话，只有明确给了其他会话 ID 时才传 `sessionId`。

页面出现在 DSH 内部，左侧也有“记忆宇宙”入口；聊天顶部视图菜单和右侧栏开始页中均有同名入口。需要最新对话时点页面“刷新数据”。

如果工具不可用，如实说明插件尚未加载，不宣称已经打开。不要退回旧的外部浏览器页面冒充内部接入。

## 数据含义

- 一颗行星对应一段真实 DSH 对话，关联网络显示可追溯关系。
- 类人脑记忆和会话记录分开保存。遗忘是记忆权重降低或休眠，DSH 会话不会因此删除、归档或隐藏。
- 召回/唤醒活动来自真实记忆事件；来源缺失保持缺失，不编造会话归属。
- 全程本地；不上传聊天，不调用联网或付费模型来刷新图。
