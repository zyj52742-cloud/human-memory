# CHANGELOG

## v0.5.0 — 2026-10-28

### 新增
- **AI skill 形态**：`skills/memory/`，复制到技能目录即可用，零配置
- `memcli.py` 命令行入口：add / recall / mood / list / stats / explain / context / sleep / wake / pin
- 面向外部的 README、LICENSE (MIT)、.gitignore
- 本地模型实测结论：qwen2.5 1.5B/3B/7B 在 8 GB 显存机器上不可用

### 修复
- `extractor.py` 缺少 `max_tokens` 限制，小模型会无限生成到上下文上限
- `localhost` 在 Windows 上优先解析 IPv6，每次调用多花 2 秒
- prompt 中的格式示例被模型照抄，改成不同句子的示例
- 同进程删除库文件后不会重建表

## v0.4.0 — 2026-10-28

### 新增
- **冲突取代**：同对象态度反转时，旧记忆标记为 `superseded`，退出召回但保留历史
- **记忆生命周期**：编辑、软删除、硬删除
- **导入导出**：JSON 备份与迁移
- **多角色**：`profile` 分区，各自独立
- **倒排索引**：召回从全表扫描改为索引查询，1 万条从 135 ms 降到 10–45 ms

### 修复
- 导入路径漏建索引，导致导入的记忆无法召回
- 写入路径 O(n²)：每次写入都跑建表 DDL + 全表比对

## v0.3.0 — 2026-10-28

### 新增
- **时间维度**：连续低迷检测、趋势方向、余波期、心结
- **心结化解改为多路证据**：时间流逝 + 明确表达 + 状态转正，一句话不足以让心结消失
- 情绪状态类不做去重（否则统计不出连续几天）
- 一键演示 `demo_timeline.py`

### 修复
- “特别愤怒”因“别”被误判为否定，情绪反转

## v0.2.0 — 2026-10-28

### 新增
- **情绪两维模型**：效价 × 唤醒度，记忆强度 = |效价| × 唤醒度
- **七因子重要性**：自我参照、情绪冲击、社会关系、身份目标、状态持续、新奇、细节
- **分类型衰减**：11 种类型各有半衰期，情绪冲击强的翻倍
- **可解释性**：`explain` 输出六因子明细
- 情绪词典扩充到约 95 个词（含口语表达）

### 修复
- 负情绪不加分（原 `max(0, emotion)` 截断）
- 情绪状态被去重，导致无法统计趋势

## v0.1.0 — 2026-10-28

### 初始版本
- SQLite 单文件存储，零第三方依赖
- 记忆分主次（规则打分）
- 休眠 / 唤醒状态机
- 钉住、手动休眠、手动唤醒
- MCP 协议服务（初版 8 个工具）
- 跨会话持久化
